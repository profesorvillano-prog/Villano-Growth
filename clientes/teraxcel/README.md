# TeraXcel Clinics

Clínica de patologías musculoesqueléticas complejas en **Puerto Varas, Chile**.
Terapia celular avanzada con láser percutáneo. Se posicionan en el vacío
terapéutico entre la kinesiología tradicional y la cirugía.

**Alcance del trabajo:** gestión de campañas Meta + tráfico a landing de dolor
lumbar (MVP, un solo avatar).
